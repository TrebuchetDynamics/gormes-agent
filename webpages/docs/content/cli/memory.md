# gormes memory

Inspect persisted memory and extractor state.

## Synopsis

```
gormes memory [flags]
gormes memory [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes memory status` | Show extractor queue depth and dead letters |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for memory |
