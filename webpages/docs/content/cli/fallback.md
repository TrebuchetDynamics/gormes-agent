# gormes fallback

Manage fallback providers.

## Synopsis

```
gormes fallback [flags]
gormes fallback [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes fallback add` | Pick a provider and model to append to the fallback chain |
| `gormes fallback clear` | Clear the fallback provider chain |
| `gormes fallback list` | Show the current fallback chain |
| `gormes fallback remove` | Remove one fallback provider |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for fallback |
