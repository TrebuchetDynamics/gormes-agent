# gormes logs

Show recent Gormes gateway logs.

## Synopsis

```
gormes logs [flags]
```

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for logs |
| `--json` | `false` | emit machine-readable JSON: `{build, source: 'gateway'|'file', entries|content, path}` |
