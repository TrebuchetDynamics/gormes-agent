# gormes telegram

Long-polls Telegram for DMs from the allowlisted chat, drives the same kernel
+ tool loop as the TUI, and persists turns to the SQLite memory store.

## Synopsis

```
gormes telegram [flags]
```

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for telegram |
