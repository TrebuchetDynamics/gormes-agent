# gormes chat

Open chat or send a single query.

## Synopsis

```
gormes chat [prompt...] [flags]
```

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for chat |
| `-q`, `--query` | (none) | send one chat query and exit |
