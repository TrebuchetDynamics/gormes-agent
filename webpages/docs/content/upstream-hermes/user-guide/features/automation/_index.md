# Automation and Orchestration

This section groups features that make Hermes run work outside a single direct chat turn.

- [Cron](./cron/) schedules one-shot or recurring jobs.
- [Persistent Goals](./goals/) continue toward an objective across turns.
- [Subagent Delegation](../tools/delegation/) spawns isolated child agents.
- [Batch Processing](./batch-processing/) runs datasets of prompts at scale.
- [Kanban](./kanban/) coordinates multi-profile task boards and worker lanes.
