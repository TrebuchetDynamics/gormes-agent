# gormes chat

Open chat or send a one-shot query.

## Synopsis

```
gormes chat [prompt...] [flags]
```

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for chat |
| `-q`, `--query` | (none) | send one one-shot chat query and exit |
