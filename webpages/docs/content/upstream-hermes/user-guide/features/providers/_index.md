# Provider and Subscription Features

This section groups Hermes features that decide which model/provider credentials handle a request and how subscription-backed provider access is exposed.

- [Provider Routing](./provider-routing/) controls OpenRouter provider preferences.
- [Fallback Providers](./fallback-providers/) switches across providers when a primary fails.
- [Credential Pools](./credential-pools/) rotates keys within one provider.
- [Subscription Proxy](./subscription-proxy/) exposes a subscription-backed OpenAI-compatible model endpoint.
