## Command groups

The [CLI reference](../cli/) is grouped by command family:

- setup and identity: `setup`, `auth`, `config`, `profile`, `model`
- chat and sessions: `chat`, `session`, `checkpoints`, `restore`
- memory and skills: `memory`, `goncho`, `skills`, `curator`
- gateways and channels: `gateway`, `telegram`, `slack`, `whatsapp`, `channels`
- tools and integrations: `mcp`, `plugins`, `claw`, `acp`
- operations: `doctor`, `status`, `logs`, `dashboard`, `update`, `uninstall`, `version`, `usage`
- automation: `cron`, `kanban`, `fallback`, `agent`, `completion`
