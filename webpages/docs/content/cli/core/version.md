# gormes version

Print gormes version.

## Synopsis

```
gormes version [flags]
```

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for version |
| `--json` | `false` | emit a machine-readable `{version, date_alias, git_commit, build_date}` JSON record (suitable for fleet automation) |
