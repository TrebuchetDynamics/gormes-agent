# Context, Memory, and Skills

This section groups features that shape what Hermes knows before and during a turn.

- [Context Files](./context-files/) and [Context References](./context-references/) inject project and user-selected material.
- [Memory](./memory/) and [Memory Providers](./memory-providers/) preserve cross-session knowledge.
- [Skills](./skills/) and [Curator](./curator/) manage reusable procedural knowledge.
- [Personality](./personality/) and [Honcho](./honcho/) shape identity and multi-agent memory behavior.
