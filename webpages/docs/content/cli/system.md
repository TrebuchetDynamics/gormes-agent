# gormes system

Enqueue system events and inspect heartbeat or presence state.

## Synopsis

```
gormes system [flags]
gormes system [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes system event` | Enqueue a system event and optionally wake heartbeat |
| `gormes system heartbeat` | Show or control heartbeat state |
| `gormes system presence` | List or update system presence entries |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for system |
