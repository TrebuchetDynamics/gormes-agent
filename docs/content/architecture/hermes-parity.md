# Hermes Parity

Gormes is Gormes-native implementation work. Hermes remains the active behavior contract for command semantics, provider behavior, gateway UX, memory expectations, and operator workflows when those upstream behaviors are current and intentional.

Use these labels in docs:

| Label | Meaning |
|---|---|
| `runtime-ready` | Verified in the current Gormes runtime. |
| `fixture-backed` | Tested against local fixtures, not necessarily live. |
| `row-backed` | Tracked in `progress.json` or planning docs. |
| `planned` | Accepted direction without shipped behavior. |
| `unverified` | Claim needs source or runtime evidence. |
