# gormes session

Inspect and export persisted sessions.

Aliases: `session`, `sessions`.

## Synopsis

```
gormes session [flags]
gormes session [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes session browse` | Browse and resume persisted sessions |
| `gormes session delete` | Delete a persisted session |
| `gormes session export` | Export a persisted session transcript |
| `gormes session list` | List recent sessions |
| `gormes session prune` | Delete old persisted sessions |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for session |
