# gormes goncho

Inspect local Goncho memory diagnostics.

## Synopsis

```
gormes goncho [flags]

```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes goncho doctor` | Diagnose local Goncho memory topology, queues, and degraded modes |
