# gormes plugins

Manage Hermes-compatible plugins.

## Synopsis

```
gormes plugins [flags]
gormes plugins [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes plugins disable` | Disable an installed plugin |
| `gormes plugins enable` | Enable an installed plugin |
| `gormes plugins install` | Install a plugin from a Git URL or `owner/repo` shorthand |
| `gormes plugins list` | List installed plugins |
| `gormes plugins remove` | Remove an installed plugin |
| `gormes plugins update` | Update a git-installed plugin |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for plugins |
