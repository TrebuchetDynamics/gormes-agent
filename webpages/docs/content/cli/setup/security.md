# gormes security

Audit gateway, channel, tool, filesystem, and credential security.

## Synopsis

```
gormes security [flags]
gormes security [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes security audit` | Run a redacted security audit with optional deep probes and safe fixes |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for security |
