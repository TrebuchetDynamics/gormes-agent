# gormes acp

Run ACP bridge tools.

## Synopsis

```
gormes acp [flags]
gormes acp [command]
```

## Subcommands

| Command | Purpose |
|---|---|
| `gormes acp client` | Connect a debug ACP client to the Go-native ACP server |
| `gormes acp serve` | Run the Go-native ACP JSON-RPC stdio server |

## Flags

| Flag | Default | Purpose |
|---|---|---|
| `-h`, `--help` | | help for acp |
